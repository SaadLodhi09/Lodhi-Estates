# Lodhi Estates — Ultra-Luxury Architectural Real Estate Platform

A flagship, multi-page luxury real estate web platform for **Lodhi Estates**, inspired by architectural digest publications, Velora Villas, and quiet luxury modernism.

---

## 🌟 Key Features

- **Pristine Bright / White Luxury Aesthetics:** Alabaster canvas, Roman travertine textures, and glassmorphism.
- **Velora-Style 100dvh Cinematic Hero:** Full-bleed edge-to-edge photography with text over empty space, floating translucent pill navigation, and interactive squircle stat cards (`180°`, `100%`).
- **Signature Residence Showcase:** Multi-category filterable gallery (`All`, `Villa`, `Penthouse`, `Modern Modular`) with double-bezel cards and specs.
- **Architectural Bento Grid:** 4-pillar architectural system (Zero-Threshold Glass, Turnkey 30–60 Day Modular, Monolithic Raw Travertine, Bilateral NDA Mandate Protocols).
- **Interactive Multi-Page Architecture (App Router):**
  - `/` — Flagship Home Page
  - `/properties` — Interactive Property Catalog (Search, Type/Enclave Filters, Price Slider, Grid/List view)
  - `/properties/[id]` — Dynamic Residence Showcase (Gallery lightbox switcher, specs bar, narrative/amenities/CAD tabs, mortgage equity modeler, agent card)
  - `/about` — Heritage since 1999, closed volume stats ($3.8B+), senior partner profiles, and global press quotes
  - `/services` — Bespoke Private Brokerage, Off-Market Sourcing, Modular Turnkey Advisory, Wealth Asset Management
  - `/neighborhoods` — Prime Enclave Intelligence (Royal Gardens, Marina Bay, Greenfield Estates)
  - `/contact` — VIP Consultation Desk & Global Office Switcher (London, New York, Dubai, New Delhi)
- **Interactive Global Features:**
  - `localStorage` Persistent Saved Favorites Portfolio & Slide-Over Drawer
  - Confidential Private Viewing Booking Modal with date/time selectors and bilateral NDA protocols
  - Top Ambient Scroll Progress Bar
  - Pure Client-Side Architecture (100% fast, 0 backend dependencies)

---

## 🛠 Tech Stack

- **Framework:** Next.js 16 (Turbopack, App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4 + Vanilla CSS Design Tokens
- **Typography:** Plus Jakarta Sans & Playfair Display / Cormorant Garamond
- **Icons:** Lucide React

---

## 🚀 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Open in browser
http://localhost:3000
```
